# CareerSync – AI Resume Scoring Dashboard 🚀

An AI-powered resume analysis dashboard that helps users upload resumes, check ATS score, analyze resume quality, and view job match recommendations.

---

## 📌 Features
- 📄 Resume Upload
- 🎯 ATS Score Analysis
- 📈 Resume Analytics Dashboard
- 💼 Job Match Suggestions
- 🌗 Light / Dark Theme
- 📱 Responsive UI

---

## 🛠 Tech Stack
- React.js
- Node.js
- Express.js
- Axios
- CSS

---

## 📊 Modules
- Dashboard
- Analytics
- Job Match
- Settings

---

## 🎯 Objective
To help users analyze resume quality and improve job-fit score using an AI-inspired dashboard.
